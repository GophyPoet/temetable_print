# Расписание → PDF

Один HTML-файл для конвертации Excel-файлов с расписанием уроков в готовый для печати PDF. Никакого сервера — всё работает прямо в браузере.

## Запуск

Просто откройте `index.html` в браузере (Chrome / Edge / Firefox).

## Возможности

- Загрузка одного или нескольких `.xlsx` файлов (drag-and-drop или выбор)
- Автоматическое определение листов с расписанием (пропуск служебных: «Предметы», «Звонки»)
- Разрешение формул с расписанием звонков из листа «Звонки»
- Один лист = одна страница A4 portrait
- Максимальное заполнение страницы, крупный шрифт
- Вертикальные названия дней недели (снизу вверх) для экономии места
- Автоматический подбор размера шрифта под плотность таблицы
- Предпросмотр всех страниц перед скачиванием
- Скачивание PDF или печать напрямую
- Отчёт об обработанных и пропущенных листах

## Структура

```
├── index.html                          # Всё приложение (единственный файл)
├── Расписание_1-4_классы.xlsx         # Пример: расписание 1-4 классов
└── Расписание_5-11_классы.xlsx        # Пример: расписание 5-11 классов
```

## Стек (всё встроено в HTML)

- **Парсинг Excel**: SheetJS (xlsx.js) — CDN
- **Генерация PDF**: jsPDF + html2canvas — CDN
- **Рендеринг**: HTML/CSS таблицы с `@media print`

## Точки настройки

Все настройки в объекте `CONFIG` в начале `<script>` в `index.html`:

```javascript
const CONFIG = {
    skipSheets: new Set(["Предметы", "Звонки"]),  // Листы для пропуска
    skipPatterns: [],                               // Подстроки для пропуска
    minFontPt: 7,                                   // Мин. размер шрифта
    maxFontPt: 14,                                  // Макс. размер шрифта
    pageMarginMm: 6,                                // Отступы страницы (мм)
    rotateDayNames: true,                           // Вертикальные дни недели
};
```

Другие точки настройки:
- `estimateFontSize()` — логика подбора шрифта по числу строк
- `DAYS` — список дней недели для определения вертикального поворота
- CSS-стили `.timetable-page` — визуальное оформление таблицы

## Допущения о структуре Excel

- Строка 1 = заголовок расписания (объединённая ячейка на всю ширину)
- Строка 2 = учителя / классные руководители
- Строка 3 = заголовки столбцов (День, №, Время, классы)
- Столбец A = дни недели (merged cells на несколько строк)
- Столбец B = номер урока
- Столбец C = время (формулы-ссылки на лист «Звонки»)
- Столбцы D+ = предметы по классам
- Если добавятся или уберутся листы с классами — всё работает автоматически
- Листы «Предметы» и «Звонки» не учитываются как страницы расписания
