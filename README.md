# Расписание → PDF

Веб-приложение для конвертации Excel-файлов с расписанием уроков в готовый для печати PDF. Каждый лист с расписанием класса — одна страница A4 portrait.

## Возможности

- Загрузка одного или нескольких `.xlsx` файлов (drag-and-drop или выбор)
- Автоматическое определение листов с расписанием (пропуск служебных: «Предметы», «Звонки»)
- Разрешение формул с расписанием звонков из листа «Звонки»
- Один лист = одна страница A4 portrait
- Максимальное заполнение страницы, крупный шрифт
- Вертикальные названия дней недели (снизу вверх) для экономии места
- Автоматический подбор размера шрифта под плотность таблицы
- Отчёт об обработанных и пропущенных листах
- Скачивание объединённого PDF

## Запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск
python run.py
```

Приложение доступно по адресу: http://localhost:5000

## Структура проекта

## Стек

- **Backend**: Python, Flask
- **Парсинг Excel**: openpyxl
- **Рендеринг**: HTML/CSS → WeasyPrint → PDF
- **Слияние PDF**: pypdf

## Точки настройки

### Фильтрация листов (`app/parser.py`)
- `SKIP_SHEETS` — множество имён листов для пропуска (по умолчанию: `{"Предметы", "Звонки"}`)
- `SKIP_PATTERNS` — подстроки в имени листа для пропуска

### Параметры макета (`app/renderer.py`)
- `PAGE_MARGIN_MM` — отступы страницы в мм (по умолчанию: 6)
- `MIN_FONT_PT` / `MAX_FONT_PT` — диапазон шрифтов (7–14)
- `ROTATE_DAY_NAMES` — вертикальный поворот названий дней недели (True)
- `_estimate_font_size()` — логика автоподбора размера шрифта по числу строк

### Формат экспорта (`app/main.py`)
- `download_name` — имя скачиваемого файла
- `ALLOWED_EXTENSIONS` — допустимые расширения

## Допущения

- Строка 1 = заголовок расписания (объединённая ячейка на всю ширину)
- Строка 2 = учителя/классные руководители
- Строка 3 = заголовки столбцов (День, №, Время, классы)
- Столбец A = дни недели (merged cells на несколько строк)
- Столбец B = номер урока
- Столбец C = время (формулы-ссылки на лист «Звонки»)
- Столбцы D+ = предметы по классам
- Если добавятся/уберутся листы с классами, всё будет работать автоматически
